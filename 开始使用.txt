PyScope — 基于 Python 的程序执行可视化与调试分析平台

一、直接运行
将压缩包完整解压，然后打开：
Windows免安装版 → PyScope → PyScope.exe
无需另外安装 Python。请保留 exe 旁的 _internal 文件夹。
启动后自动打开浏览器，默认地址 http://127.0.0.1:8765。
使用期间保留启动窗口；结束时按 Ctrl+C 关闭服务。

三、五分钟体验
1. 递归阶乘：启动后单步，给第4行设置断点，继续并查看调用栈。
2. 链表与循环引用：运行到结束，观察 A → B → C → A 的引用关系。
3. 拖动时间线：比较各个已保存快照，查看变量与输出变化。
4. 定位除零异常：运行到异常，查看第4行及 count=0。
5. 性能实验：重复递归运行分析并保存基准，再分析记忆化递归。
6. 语法结构：解析代码，展开真实 AST 节点。

四、源码与验证
源码、自动测试和重建脚本都在本目录；详细说明见 README.md。
源码版可使用 start.bat 启动（需要 Python，首次安装依赖需联网）。
docs 中保存实测数据、自动测试日志、界面截图及设计说明。
演示前请在实际答辩电脑上完整启动一次，并熟悉演示脚本中的原理说明。

五、v1.1.0 服务器版
新增账号登录、运行记录权限控制和 rootless Docker 代码隔离。
Linux 服务器安装 requirements-server.txt，通过 server.py 初始化账号、检查环境并启动。
没有默认密码；没有域名时可使用 SSH 隧道访问。详细步骤见 deploy/README.md。
Windows 免安装版仍用于本机可信代码；不要将本地入口改成公网监听。
