## 1. 需求来源与范围

用户选择纯软件 Python 课程项目，希望具有较高技术难度、清晰的动态展示和可讲解的技术深度。项目确定为程序执行可视化与调试分析平台。登记表的个人与成员信息由用户要求留空；系统实现和提交材料不能据此虚构身份或工作分配。

核心演示围绕真实 Python 程序执行，包含代码编辑、单步与断点、变量与对象引用、调用栈、执行历史、AST、性能分析和本地记录。多线程、异步和不可信代码执行不列入本次承诺范围。

## 2. 2026 年 10 月 12 日：技术调研

实际事项：读取项目实现约定，查阅 Python 与 Flask 官方文档，核对跟踪事件、语法树、函数性能分析、子进程与本地持久化能力。

形成的判断：

- line 事件在执行源码行之前触发，界面应采用相同语义。
- 单步调试需要真正暂停工作进程内的执行，不能只播放已经完成的动画。
- 可变对象需要稳定标识和引用关系，否则无法解释别名与循环引用。
- 执行历史用于快照回放，不承诺撤销外部副作用。
- 性能分析独立执行，避免将手动暂停时间解释为程序耗时。
- 本地子进程用于执行管理，不等同于安全沙箱。

证据：`ARCHITECTURE.md`、`docs/技术参考.md`。本阶段未产生可用于证明所有功能已完成的测试结果。
