# PyScope 答辩演示脚本

题名：基于 Python 的程序执行可视化与调试分析平台  
讲解长度：建议 6–8 分钟；这是排练安排，不是实测用时。  
界面操作：执行调试、语法结构与性能实验。

## 演示前准备

按 README 启动本地服务，打开浏览器，确认示例菜单、编辑器与各面板已显示。关闭不需要的后台程序，放大页面到现场可读的程度。先运行一次下列示例，确认变量、对象、输出和历史行为。准备一份完整执行记录作为现场恢复材料；恢复历史时明确说明正在展示已保存记录。

姓名、学号、班级与成员信息在提交时补充。讲解时结合源代码说明执行控制、快照采集和界面联动的实现过程。

## 1. 项目目标（约 40 秒）

“我的项目是 PyScope，一个在本地运行的 Python 程序执行可视化与调试分析平台。它解决的是一个学习中的具体问题：程序已经输出结果，但我们仍然不知道变量在什么时候改变、递归调用为什么增加、两个变量为什么会同时变化。因此，平台把真实 Python 执行事件转换成代码高亮、变量状态、对象引用和调用栈，并保留历史快照供回看。”

展示编辑器、变量、对象、调用栈和时间轴，说明这些视图对应同一时刻的快照。

## 2. 真单步与对象别名（约 90 秒）

载入以下代码，或使用交付示例中相同语义的代码：

```python
original = [1, 2]
alias = original
copied = original.copy()
alias.append(3)
print(original, alias, copied)
```

点击开始调试。第一行高亮时先解释：“当前高亮表示即将执行，因此变量还没有出现。”单步推进到第二行，指出 `original` 现在出现。执行别名赋值后展示 `original` 与 `alias` 指向同一对象；再执行复制，指出 `copied` 是另一个对象。执行 `append` 后比较两个对象内容。

程序输出为 `[1, 2, 3] [1, 2, 3] [1, 2]`。

“这说明变量名与对象不是同一概念。平台并没有简单地打印三个列表，而是保存引用关系，使共享对象可以被直接观察。”

拖动时间轴回到修改前，再回到修改后。说明这一步是在查看快照，程序不会重新执行，外部副作用也不会撤销。

## 3. 递归、断点与调用栈（约 90 秒）

使用内置递归示例，或粘贴：

```python
def factorial(n):
    if n <= 1:
        return 1
    partial = factorial(n - 1)
    return n * partial

result = factorial(4)
print(result)
```

在第 4 行设置断点，开始调试后继续运行。每次到达断点，观察 `n` 与栈深度的变化。选择不同栈帧，解释同名 `n` 在不同函数调用中拥有不同值。随后继续到结束，观察返回过程和最终输出 `24`。

“引擎用执行跟踪事件采集栈帧，每个栈帧保存自己的局部变量。单步会进入函数，所以它与 IDE 中的单步跳过不同。”

## 4. 静态结构与动态事件（约 50 秒）

打开 AST 面板，展示函数、条件分支、调用和返回等节点。

“AST 来自语法解析，反映代码写了什么。调用栈和事件历史来自实际执行，反映这一次运行发生了什么。同一段代码只有一个函数定义，但一次运行可以产生多个递归栈帧。AST 中的循环节点数也不等于运行中的循环次数。”

将一处冒号删除，触发语法分析错误，展示定位信息；随后恢复代码。

## 5. 性能分析（约 60 秒）

选择带多个函数的内置性能示例并运行性能分析。指出函数调用次数、自身耗时和累计耗时之间的区别。

“性能分析会独立重新运行代码。调试过程包含暂停和快照开销，不能直接拿来评价算法速度。这里的统计用于发现函数热点。附带实验把两个斐波那契实现的输入都设为 22，每种运行 5 次，输出均为 17711。重复递归调用 57313 次，记忆化递归调用 43 次。调用次数说明重复计算的减少，计时还会受到运行环境影响。”

只讲解现场实际统计，不预先编造速度提升倍数。

## 6. 记录保存与结束（约 40 秒）

导出一次执行记录，打开历史列表，载入刚才的运行。说明历史包含源码和事件，可用于课后复现与分析。

“项目的主要实现是执行控制、引用关系快照、多视图同步与记录管理。它目前面向可信的单线程同步教学代码。子进程负责执行管理，并不是安全沙箱。下一步可以扩展条件断点与更节省空间的快照存储。”

## 常见问题与回答要点

| 问题 | 回答要点 |
| --- | --- |
| 动画是否事先写好？ | 不是。当前显示来自目标程序运行时事件与快照。换代码后会生成另一条事件序列。 |
| 如何证明是真单步？ | 用赋值或输出代码停在首行，观察值在点击单步前不变化；可通过自动检查验证被执行代码尚未推进。 |
| 为什么高亮行与变量值看起来差一行？ | `line` 事件发生在执行该行之前，高亮是下一条要执行的行。 |
| 为什么两个变量指向同一对象？ | Python 名字绑定对象，直接赋值并不复制可变容器。 |
| 如何避免循环引用无限展开？ | 序列化先登记对象标识，遇到已访问对象仅记录引用，同时限制展开规模。 |
| 时间轴能不能让程序真正倒退？ | 当前功能是读取旧快照，不能撤销文件或网络等副作用。 |
| 为什么性能分析要重新运行？ | 调试会加入暂停和序列化开销，独立运行更适合观察函数耗时分布。 |
| 为什么不直接在 Flask 进程里执行？ | 子进程使停止、超时和执行状态管理独立于 Web 服务；但不提供完整安全隔离。 |
| 有没有实现多线程和异步调试？ | 当前没有承诺这些语义；支持范围是可信的单进程单线程同步代码。 |
| 哪些是第三方能力，哪些是本项目实现？ | Python 提供追踪、AST 与性能接口，Flask 提供 HTTP 服务；项目实现会话状态、控制协议、对象快照、视图联动和历史管理。 |
| 项目的创新点是什么？ | 将真实执行、引用语义、结构分析和运行历史组织成连续可解释的学习过程；不把使用现有库本身表述为算法原创。 |

## 现场异常处理

如果程序因事件或时间限制停止，展示限制提示并改用较小输入；不要把停止说成算法正常完成。如果运行历史为空，先完整运行一个示例再打开历史。如果浏览器连接中断，检查本地服务是否仍在运行。若现场只能使用保存记录，应明确告诉老师这是之前导出的记录，并继续解释其中的真实状态。
