## 核对后采用的技术判断

1. `sys.settrace` 可以提供实现源代码调试器所需的事件。项目据此设计单步和断点，但要自己实现暂停条件、命令协议与状态快照。它的逐行事件语义不是任意指令级执行回退。[R1](https://docs.python.org/3/library/sys.html#sys.settrace)
2. AST 分析不需要执行代码，因此可以先进行语法校验和结构展示。AST 本身不能保证运行正确，也不能代替实际执行路径分析。[R2](https://docs.python.org/3.12/library/ast.html)
3. cProfile 提供确定性函数分析；自身耗时与累计耗时含义不同。统计适用于定位热点，严格微基准应使用合适的方法和重复实验。[R3](https://docs.python.org/3.12/library/profile.html)
4. 子进程让执行退出和通信管理更明确，但单纯创建子进程不会限制其文件或网络访问权限。可信代码边界来自本项目的运行方式。[R4](https://docs.python.org/3/library/subprocess.html)
5. SQLite 无需独立服务器，适合本地历史持久化。它负责保存记录，不负责将程序状态恢复为活跃解释器。[R5](https://docs.python.org/3.12/library/sqlite3.html)
