# 腾讯云无域名部署说明

可以不用域名：在腾讯云 Linux 服务器上运行 PyScope，再通过 SSH 隧道用自己电脑的浏览器访问。当前版本仅监听服务器的 `127.0.0.1`，并校验 Host 为 `localhost` 或 `127.0.0.1`，适合可信单用户课程演示。

本说明尚未在你的腾讯云服务器上执行。需要服务器公网 IP、可登录的非 root 用户、SSH 访问权限，以及 Git、Python 3.10 或更新版本、venv 和 pip。现有项目实测环境为 Windows；Linux 的系统依赖需按实际发行版确认。

## 1. 在服务器上启动

先从自己电脑登录服务器，将下方“用户”和“服务器公网IP”替换为真实值：

```bash
ssh 用户@服务器公网IP
```

使用非 root 用户，在有写入权限的工作目录执行。仓库公开发布后可从以下地址获取：

```bash
git clone https://github.com/1911661808-code/PyScope.git
cd PyScope
python3 --version
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python app.py --port 8765 --no-open
```

确认 Python 版本至少为 3.10；若缺少 `venv` 或 pip，先按服务器发行版补齐系统组件。保持这个终端运行。软件会在服务器本机提供 `http://127.0.0.1:8765`，不会直接对公网开放。

## 2. 在自己电脑上建立隧道

另开一个本机终端，执行：

```bash
ssh -N -L 127.0.0.1:18765:127.0.0.1:8765 用户@服务器公网IP
```

本机使用 `18765`，避免与已经运行的本地 PyScope `8765` 端口冲突。`-N` 只建立连接而不运行远程命令；`-L` 将本机端口通过 SSH 转发到服务器本地服务。该终端保持运行即可。[OpenSSH 参数说明](https://man.openbsd.org/ssh#L)

随后在自己电脑的浏览器打开：

```text
http://localhost:18765
```

如果本机 `localhost` 优先使用 IPv6 导致连接失败，可改用 `http://127.0.0.1:18765`。若 SSH 使用非默认端口，两次 SSH 命令都补充 `-p 实际SSH端口`。

## 3. 安全组与运行方式

该方案只使用既有 SSH 连接规则，通常是 TCP 22；按现有配置允许自己的来源地址访问即可。无需开放服务器的 8765，也无需为这条隧道新增 80 或 443 规则。腾讯云安全组按实际需要放行端口，SSH 与 Web 端口是不同规则。[腾讯云安全组官方说明](https://www.tencentcloud.com/document/product/213/15377)

上面的服务以终端前台方式运行。按 Ctrl+C 或关闭运行服务的 SSH 终端会结束服务；关闭隧道终端会断开本机访问。长期运行可改用 systemd 管理，但服务用户、工作目录、解释器路径和开机启动配置须等实际服务器系统确认后适配。

当前 Flask 内置服务仅用于可信个人课程演示。执行的 Python 代码拥有服务用户的文件与网络权限，子进程不是安全沙箱。公网多人使用需要先实现身份认证与真正的执行隔离，并采用合适的部署服务；本说明不修改当前监听地址或绕过 Host 限制。
